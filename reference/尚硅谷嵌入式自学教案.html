0开篇：先定节奏，再谈内容

这份教案的前提假设：你有 7 年前端工程经验，逻辑与工程能力不缺，缺的是硬件常识、C 语言底层、以及「对着板子调通」的手感。

三条定调结论（先看这三句，再往下读）
  • ① C 语言那一章可以压缩：语法你基本都会，真正要补的是 指针与内存布局、位运算、const/volatile/static、内存分区——这四项直接决定你能不能看懂寄存器操作。
  • ② 模电不用啃教材：尚硅谷第一阶段的「电子元器件 + 数字电路」目标是「看得懂原理图、算得出限流电阻」，不是培养硬件工程师，够用即止。
  • ③ 你的差异化在「屏 + 交互」：LVGL、Qt、上位机界面是你的主场（前端审美与交互经验可迁移），这是纯硬件出身的候选人做不了的，后文会展开。

1阶段一 · 软硬件基础（约 4 周）

这一阶段决定你后面是「跟着敲代码」还是「真的懂」。目标不是成为硬件工程师，而是：看得懂原理图、算得出参数、量得到波形、写得出能落地的 C。

1.1 嵌入式电子元器件 4 天 · 动手为主
▸

关键知识点

  • 电阻：阻值/精度/功率/封装（0402、0603、0805）；上拉与下拉的取值逻辑；分压与限流计算；0Ω 电阻的作用（跳线、单点接地）。
  • 电容：陶瓷/电解/钽电容的区别；去耦（decoupling）与旁路为什么每个芯片电源脚都要配 0.1µF；「104」「106」的读数法；耐压与降额。
  • 电感与磁珠：储能（DC-DC 必备）、抑制高频噪声；DCR 与饱和电流。
  • 二极管：整流、续流、稳压（齐纳）、肖特基（低压降）、TVS（防浪涌）、LED 限流电阻公式 R=(Vcc−Vf)/I。
  • 三极管：NPN/PNP 作开关，饱和区与放大区的判据，基极限流电阻怎么算。
  • MOS 管：NMOS 低边开关 / PMOS 高边开关，栅极电荷与驱动，Rds(on) 选型；为什么电机要用 MOS 而不是三极管。
  • 晶振与时钟：无源晶振 + 两个负载电容的匹配；有源晶振；复位电路（RC + 按键）。
  • 电源：LDO 与 DC-DC 的取舍（效率 vs 噪声）、压差、发热估算。

必做实验

  • 面包板点亮 LED，用三种阻值对比亮度，实测电流验证限流公式。
  • 三极管驱动继电器 / 蜂鸣器；MOS 管驱动小直流电机（一定要加续流二极管）。
  • RC 低通滤波，用示波器看方波被「磨圆」的过程，改 R/C 看截止频率变化。
验收：给你一张陌生模块的原理图，能指出电源路径、去耦电容、上拉电阻、限流电阻各自的作用，并说出任意一个电阻为什么是这个阻值。
1.2 C 语言精讲（按你的基础做减法） 8 天 · 只补底层
▸

尚硅谷《C 语言核心技术》覆盖很全（常量变量 → 分支循环 → 数组指针 → 函数 → 预处理 → 内存存储）。你有编程基础，跳过语法讲解，只精读下列六块，其余用「写代码时查漏」的方式补。

必须精读的六块

  • 指针：指针与数组的退化关系、二级指针、函数指针与回调、指针运算与步长、野指针与 NULL 判定。嵌入式里所有寄存器操作、驱动回调都靠它。
  • 内存布局：栈 / 堆 / .data / .bss / 常量区 / 代码区，各自放什么、什么时候被清零。这是理解「全局变量为什么初值为 0、局部变量为什么不一定是 0」的唯一途径。
  • 位运算：置位 |=、清零 &=~、取反 ^=、移位、提取字段。这一块要练到「看代码就知道在操作哪个 bit」。
  • 结构体 / 联合体 / 位域 / 内存对齐：协议报文解析、寄存器映射全靠它；#pragma pack 与对齐的坑。
  • static / const / volatile / extern：四个关键字在嵌入式里的真实语义（volatile 为什么必须加在寄存器变量和中断共享变量上）。
  • 预处理：宏与函数的取舍、条件编译（#ifdef DEBUG）、头文件卫士、## 拼接。

必做实验

  • 用纯 C 写一个环形缓冲区（ring buffer），支持满/空判定，用于串口收数据。
  • 用函数指针数组实现一个简易状态机（比如按键的短按/长按/双击）。
  • 用宏封装一组寄存器位操作，然后在 gcc -S 下看汇编，确认自己写的位运算被编译成了什么。
  • 故意制造一次数组越界，观察栈被破坏后的诡异现象（比看十页书都深刻）。
验收：能手写 ring buffer 与位操作宏；能解释 volatile 在中断服务函数里的必要性；能画出自己程序的 .map 内存分布。
提醒：C 语言的「考试型知识」（如复杂的指针表达式解析）不必深究，面试偶尔问，工作中极少用。把时间投给位运算和内存。
1.3 数字电路：从零搭建计算机 4 天 · 建立世界观
▸

关键知识点

  • 数制与编码：二进制、补码（为什么用补码做减法）、BCD、ASCII、格雷码。
  • 逻辑门与布尔代数：与或非、异或、德摩根定律；用真值表化简。
  • 组合逻辑：半加器 → 全加器 → 多位加法器、译码器、编码器、多路选择器。
  • 时序逻辑：RS/D 触发器 → 寄存器 → 计数器 → 分频器；建立/保持时间的概念。
  • 总线、时钟、复位、三态门：为什么多个器件能共用一根数据线。
  • 从门电路到 CPU：ALU、指令寄存器、程序计数器、取指-译码-执行周期。

必做实验

  • 用 Logisim 搭一个 4 位加法器，再用触发器搭一个 4 位计数器，接上七段数码管显示。
  • 把「8 个 LED 轮流亮」拆解成「移位寄存器 + 时钟」模型，理解代码里的循环延时究竟在替代什么硬件。
验收：能用自己的话讲清「一个电平变化怎么变成一条指令的执行」；看到 GPIOA->ODR |= 1<<5 能对应到硬件上的哪个门、哪个触发器。
1.4 原理图 & PCB 设计 5 天 · 有产出
▸

尚硅谷这套课的特色是「每个元件都讲原理、每根线都说清为什么」，最终完成一块多层板实战。自学时按下面顺序走，最后一定要打样一次。

关键知识点

  • 工具：嘉立创 EDA（免费、库全、可直接下单打样）；元件库 / 封装库 / 3D 预览。
  • 原理图：电源树（Type-C 取电 → 自恢复保险丝 → 滤波 → LDO 5V→3.3V）、去耦网络、复位电路、BOOT 选择、SWD 调试口、晶振。
  • PCB：层叠设计、布局优先级（电源 → 晶振 → 接口 → 高速）、布线线宽与载流（1oz 铜约 1mm/1A 的经验值）、地平面完整性与回流路径、丝印规范。
  • 生产文件：BOM、坐标文件（Pick&Place）、Gerber；打样与 SMT 贴片下单流程。

必做实验

  • 画一块 STM32 最小系统板（含 USB 供电、SWD、复位、BOOT、用户 LED、按键）。
  • 打样 5 片，自己用烙铁/风枪焊 1 片，上电、烧录、点灯。这一步是整个阶段的高光时刻，也是最有用的简历素材。
验收：板子能烧录并点亮 LED；能讲清每个模块为什么这样连；能用万用表排查一次焊接虚焊。
1.5 万用表 / 直流电源 / 示波器 / 逻辑分析仪 3 天 · 调试基本功
▸

关键知识点

  • 万用表：通断档查线路、直流电压档查供电、电流档查功耗（注意串接与量程）、二极管档测 PN 结。
  • 直流电源：先设电压再开输出、限流保护（调试新板子必开，防止冒烟）、看电流判断是否短路。
  • 示波器：探头 ×1/×10 的区别与补偿、时基与垂直档、触发方式（边沿/电平）、测 PWM 频率与占空比、用 Math 做差、看串口波形。
  • 逻辑分析仪：采样率与通道数、协议解码（UART/I2C/SPI），抓 I2C 的 start/ack/stop。

必做实验

  • 示波器测 STM32/51 输出的 PWM，读出频率与占空比，再改代码验证。
  • 逻辑分析仪抓一次 I2C 读 EEPROM 的完整时序，对照数据手册逐个字节核对。
  • 用电源的电流读数判断板子是否短路（短接 3.3V 与 GND 试一次，看到限流触发）。
验收：遇到「板子不亮」时，能按「供电 → 复位 → 时钟 → 程序」四步顺序用仪器定位，而不是盲目换元件。

2阶段二 · 51 单片机开发（约 3 周）

为什么 2026 年还要学 51？不是因为 51 有用，而是因为它结构简单、没有库、全部寄存器裸奔，能把「外设—寄存器—现象」这条因果链走通一遍。走通之后上 STM32，你只是换了一套更复杂的寄存器，逻辑是同一套。

2.1 8051 架构、最小系统与开发环境 4 天
▸

关键知识点

  • 8051 内部结构：CPU、ROM/RAM、SFR（特殊功能寄存器）、时序（机器周期 = 12 个时钟）。
  • 最小系统：电源、晶振（11.0592MHz 为什么是串口常用值）、复位电路、EA 引脚。
  • Keil C51 工程创建、编译、烧录（STC-ISP）、sbit / sfr 的用法。
  • IO 口结构：准双向口的弱上拉，为什么 51 的 P0 口要外接上拉电阻。

必做实验

  • 点亮第一个 LED（软件延时），再用 _nop_() 与定时器对比延时的准确性。
  • 按键输入：软件消抖（延时 10ms 再判断）与硬件消抖（RC）对比。
验收：能说清「写 1 到 P1 寄存器 → 引脚变高 → LED 亮」中间每一步发生在哪个硬件上。
2.2 中断系统与定时器/计数器 4 天
▸

关键知识点

  • 中断源、中断向量、中断优先级、中断嵌套；interrupt n 关键字。
  • 外部中断 INT0/INT1 的触发方式（电平/边沿）。
  • 定时器 T0/T1 的四种工作模式、初值计算、溢出与自动重装。
  • 用定时器产生精准延时与 PWM（软件 PWM 与硬件 PWM 的差别）。

必做实验

  • 定时器中断实现 1 秒精准闪烁，并用秒表或逻辑分析仪核对误差。
  • 按键外部中断控制流水灯启停；中断里只置标志，主循环处理逻辑（这个习惯要一开始就养成）。
验收：能解释「为什么中断服务函数里不要做延时和打印」；能算出任意定时时长的初值。
2.3 串口通信与显示（数码管 / LCD1602） 4 天
▸

关键知识点

  • UART 帧格式、波特率计算（11.0592MHz 的妙处）、TTL 与 RS232/RS485 电平差异。
  • 串口收发：轮询与中断两种方式；printf 重定向到串口。
  • 数码管：共阴/共阳、段码表、动态扫描与视觉暂留、限流电阻。
  • LCD1602：指令集、初始化时序、忙标志判断、显示自定义字符。

必做实验

  • 串口助手双向通信：上位机发指令控制 LED，单片机回传状态。
  • 数码管做一个 60 秒倒计时；LCD1602 显示温湿度（配合后续传感器）。
验收：能独立排查串口乱码（波特率 / 时钟 / 电平 / 接线四类原因）。
2.4 总线与常用外设：I2C / SPI / 单总线 / AD-DA 5 天
▸

关键知识点

  • I2C：两根线（SCL/SDA）、开漏 + 上拉、起始/停止/应答时序、7 位地址；读写 AT24C02。
  • SPI：四线（SCK/MISO/MOSI/CS）、四种模式（CPOL/CPHA）、全双工；读写 W25Qxx Flash。
  • 单总线：DS18B20 的复位/存在脉冲、ROM 命令、温度转换时序（微秒级延时是难点）。
  • AD/DA：ADC0809 或内部 ADC 的转换原理、参考电压、分辨率；DAC 输出正弦波。
  • 红外 NEC 协议：38kHz 载波、引导码、地址/数据反码。

必做实验

  • 软件模拟 I2C 完整读写 EEPROM，断电后数据不丢。
  • DS18B20 采集温度并显示到 LCD；红外遥控解码并在串口打印键值。
验收：不看教程能凭数据手册手写出 I2C 读写单个字节的时序函数；用逻辑分析仪抓波形自查。
2.5 电机驱动与 PWM 控制 3 天
▸

关键知识点

  • 直流电机：H 桥原理、正反转、PWM 调速、续流保护。
  • 步进电机：四相八拍、细分驱动、丢步原因。
  • 舵机：20ms 周期、0.5–2.5ms 脉宽对应角度。

必做实验

  • L298N 驱动小车前进/后退/差速转向；舵机云台扫掠。
验收：能算清「电池电压 → 电机电流 → 驱动芯片发热 → 是否要加散热片」这条链。
2.6 阶段项目：51 智能小车 1 周 · 阶段产出
▸

功能要求

  • 红外/超声波避障 + 循迹（光电对管）+ 蓝牙遥控（HC-05）+ OLED 显示状态。
  • 用状态机组织代码，而不是一堆 if-else；每个模块一个 .c/.h。

5.2 Linux 应用层开发（130 集体系，按 7 个模块推进） 4 周
▸

模块一 · C 开发与构建（约 1 周）

  • POSIX 标准；GCC 编译四阶段（预处理 / 编译 / 汇编 / 链接）；静态库与动态库。
  • Makefile：变量、自动推导、伪目标、模式规则、多目录工程。这是 Linux 开发的「水电煤」。
  • GDB 调试：断点、单步、查看内存、core dump 分析；valgrind 查内存泄漏。

模块二 · 文件 IO 与系统调用（约 3 天）

  • 标准 C 库：fopen/fread/fwrite/fprintf/fscanf；缓冲机制。
  • 系统调用：open/read/write/close/lseek/stat；文件描述符的本质（进程 fd 表 → 系统打开文件表 → inode）。
  • 标准输入输出错误 stdin/stdout/stderr 与重定向。

模块三 · 进程（约 4 天）

  • fork 创建子进程（写时复制）、execve 替换映像、waitpid 回收。
  • 进程树、孤儿进程、僵尸进程的成因与处理。
  • 守护进程（daemon）的创建步骤：fork → setsid → 重定向标准流 → 改工作目录。

模块四 · 进程间通信 IPC（约 3 天）

  • 匿名管道、有名管道（FIFO）、共享内存（shm_open/mmap）、消息队列、信号（signal/sigaction）。
  • 各自的适用场景与性能对比；共享内存为什么要配信号量做同步。

模块五 · 线程与同步（约 1 周）

  • pthread_create/join/detach/cancel；线程与进程的本质区别（共享地址空间）。
  • 竞态条件；互斥锁、读写锁、自旋锁、条件变量、信号量五件套的适用场景。
  • 条件变量为什么必须配 while 而不是 if（虚假唤醒）。
  • 线程池：原理、任务队列、 worker 线程、优雅退出。

模块六 · 内核原理（约 3 天）

  • 操作系统分层、PCB 与内存模型、CPU 工作模型、进程状态迁移。
  • 虚拟内存与物理内存映射、缺页异常、fork 的写时复制实现。
  • 系统调用与库函数的关系、上下文切换流程。

模块七 · 网络编程（约 1 周）

  • OSI 七层与 TCP/IP 四层、数据封装与解封装。
  • TCP 三次握手 / 四次挥手、滑动窗口、拥塞控制；UDP 特性。
  • Socket 编程：socket/bind/listen/accept/connect/send/recv；字节序转换。
  • 多连接服务端：多进程 / 多线程 / IO 多路复用（select / poll / epoll） —— epoll 是面试必考。

本阶段产出（非常重要）

  • 一个完整的 C/S 项目：比如「多线程 TCP 服务器 + 客户端」，支持并发连接、心跳、断线重连、日志记录、配置文件读取。放到 GitHub 上，这是 Linux 岗简历的核心项目。
验收：能手写 Makefile 编译多目录工程；能解释「一个 TCP 连接在内核里占用哪些资源」；能用 epoll 写出支持 100+ 并发的服务端。

关键知识点

5.4 驱动开发：字符设备 / platform 总线 / 设备树匹配 3 周

关键知识点

  • 内核模块：module_init/exit、printk、Makefile 与内核源码树、insmod/rmmod/lsmod；GPL 协议。
  • 字符设备：主次设备号、cdev、file_operations（open/read/write/ioctl/release）、copy_to_user/copy_from_user。

⚠避坑清单（前端转嵌入式最容易踩的 10 个坑）

10 条，逐条对照，中一条就停下来改
▸
  • 1. 只看视频不动手。嵌入式的知识密度在「现象」里，不在「讲解」里。视频看懂 ≠ 会做，必须 1:2 配比动手。
  • 2. 陷进模电教材。《模拟电子技术》可以当字典查，不要从头读到尾。你需要的只是「看得懂 + 算得出」。
  • 3. 一上来只学 HAL 库。只会 HAL 的人，遇到问题是盲的。寄存器必须走一遍，哪怕只走 GPIO、串口、定时器三个。
  • 4. 买最便宜的板子。没有原理图、没技术支持、没例程的板子，会让你 80% 的时间花在找资料上。
  • 5. 跳过 Makefile 和 Shell。Linux 阶段的所有痛苦，一半来自不会看编译错误和脚本。
  • 6. 不做笔记，反复回看。每个外设建一页「寄存器 + 坑点」笔记，复习成本会下降 5 倍。
  • 7. 追求做「很多项目」，每个都只做一半。两个做深 > 十个做浅。面试只问细节。
  • 8. 代码全塞在 main.c。从阶段二开始就分模块（bsp / driver / app），否则到 STM32 阶段你会被自己写死。
  • 9. 不用 Git。每天 commit 一次，一是留痕，二是简历上能给面试官看真实过程。
  • 10. 等到「学完」才找工作。阶段三结束（约 W16）就可以开始投「嵌入式软件助理/实习」，边面边补，面试反馈是最好的学习大纲。
最后一句实话：这套大纲的内容量，按尚硅谷面授的节奏是 5–6 个月全日制。自学最大的敌人不是难度，是「没有外部节奏」——没人催、没人答疑、没人告诉你「这题不用深究」。所以：① 固定每天同一时段开工；② 每周日给自己做一次「里程碑验收」，不达标就补，别往下走；③ 找一个能问问题的地方（板厂论坛/技术群），卡超过 2 小时就去问，别硬耗。
